# W-mass-measurment-FCCee

Starting date: 

This repository contains my contributions to W mass studies at FCC-ee within the Hadronic Structure and QCD collaboration:

https://github.com/hsqcd-collab

This is an ongoing team project. Some parts of the work are based on collaboration-wide efforts, and not all collaboration code is included here. This repository mainly collects the parts I am currently working on, testing, and improving step by step.

The main reference used for the W mass reconstruction part is:

Marina Béguin, *Calorimetry and W mass measurement for future experiments*

The current baseline work is organized around two main parts:

- `angular-resolution`
- `kinematic-fit`
