# ISR truth-correlation and efficiency report

Input: `wmass_fit_pvalue_pulls_ISR_ecm162p5.root`

Correlations are calculated only for events on which the ISR fit was applied. Counts from different true-ISR slices are not compared as raw yields. Instead, each efficiency uses an explicit within-slice denominator.

- Eligible: standard fit valid and `0 < P < 0.03`.
- Attempt efficiency: attempted / eligible.
- Fit-valid efficiency: valid ISR solution / attempted.
- Recovery efficiency: final ISR probability above 3% / applied.
- Coverage: applied / standard-valid events in the same truth slice.
